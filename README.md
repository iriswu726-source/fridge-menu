# 冰箱週菜單

用冰箱裡現有的食材，自動排出 7 天的早餐、午餐、晚餐和加餐，並對照成人每日營養建議檢查缺口。介面是手帳風格（點格紙、紙膠帶、螢光筆標記）。

## 三種目標模式

| 模式 | 熱量 | 蛋白質 | 排菜偏好 |
| --- | --- | --- | --- |
| 減脂 | 維持量 × 80%（女 ≥ 1200、男 ≥ 1500 kcal） | 1.6 g/kg | 高蛋白、低脂、蔬菜多；用油 ×0.6，蔬菜份量不縮減；醣類 40–55% |
| 維持 | 維持量 | 1.1 g/kg | 均衡、菜色輪替；醣類 50–60% |
| 增肌 | 維持量 × 110% | 1.8 g/kg | 高蛋白、主食足；加餐加入豆漿、優格、蛋與堅果 |

每個模式也會依你冰箱的食材列出推薦菜色。

直接用瀏覽器打開 `index.html` 就能用，不需要安裝任何東西。

## 功能

- **冰箱庫存**：輸入食材和數量（顆、片、g、ml），可以把快過期的食材標成「優先」，會優先排進菜單。資料只存在你的瀏覽器裡（localStorage）。
- **自動排菜**：從 38 道家常菜（12 道早餐、26 道午晚餐）中挑選，挑的時候看四件事：冰箱食材齊不齊、有沒有用到優先食材、當天還缺哪些營養、同一道菜是不是最近才吃過。每排一餐就扣掉用掉的食材。
- **份量調整**：依熱量目標自動放大或縮小每餐份量（早 24%、午 32%、晚 28%），剩下的由水果、乳品加餐補足。
- **營養檢查**：每天的熱量、蛋白質、脂肪與醣類占比、膳食纖維、鈣、鐵、維生素 C，以及蔬菜、水果、乳品份數，都用表格標出達標、接近或不足。
- **換菜**：點菜名可以看其他候選菜色和它們的食材齊全度，選一道替換。
- **補買清單／剩餘食材**：列出冰箱不夠、需要補買的食材（可一鍵複製），以及一週後冰箱還剩什麼。
- **多人用餐**：設定人數後，扣庫存和補買數量都會乘上人數；畫面上的份量是每人份。

## 營養目標

依衛福部《國人膳食營養素參考攝取量》第八版（19–50 歲）和《每日飲食指南》：

| 項目 | 目標 |
| --- | --- |
| 熱量（維持） | 體重 × 25／30／35／40 kcal（依活動量） |
| 蛋白質 | 維持 1.1、減脂 1.6、增肌 1.8 g／kg |
| 脂肪／醣類 | 占熱量 20–30%／50–60%（減脂醣類 40–55%） |
| 膳食纖維 | 14 g／1000 kcal（減脂至少 25 g） |
| 鈣 | 1000 mg |
| 鐵 | 女 15 mg、男 10 mg |
| 維生素 C | 100 mg |
| 蔬菜／水果／乳品 | ≥ 3 份／≥ 2 份／1.5–2 杯 |

食材營養素是參考台灣食品營養成分資料庫的近似值。本工具僅供日常飲食規劃參考，有特殊飲食需求請諮詢營養師。
