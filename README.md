# 冰箱週菜單

用冰箱裡現有的食材，自動排出 7 天的早餐、午餐、晚餐和加餐，並對照成人每日營養建議檢查缺口。介面是手帳風格（點格紙、紙膠帶、螢光筆標記），資料只存在你的瀏覽器裡。

直接用瀏覽器打開 `index.html` 就能用，也可以部署到 Netlify（見下方）。

## 三種目標模式

| 模式 | 熱量 | 蛋白質 | 排菜偏好 |
| --- | --- | --- | --- |
| 減脂 | 維持量 × 80%（女 ≥ 1200、男 ≥ 1500 kcal） | 1.6 g/kg | 高蛋白、低脂、蔬菜多；用油 ×0.6，蔬菜份量不縮減；醣類 40–55% |
| 維持 | 維持量 | 1.1 g/kg | 均衡、菜色輪替；醣類 50–60% |
| 增肌 | 維持量 × 110% | 1.8 g/kg | 高蛋白、主食足；加餐加入豆漿、優格、蛋與堅果 |

模式按鈕在最上面的「個人設定」裡；設定好之後可以收起來，只顯示一行摘要。點一下切換模式並展開說明，再點一次同一個模式就收起來；說明裡也會依你冰箱的食材列出推薦菜色。

## 功能

- **打勾「已吃」**：今天的每一餐和加餐都可以打勾，勾了就把那餐用到的食材從冰箱扣掉；取消勾選會加回去。過了那天，菜單會自動從新的一天開始排。
- **冰箱庫存與到期日**：輸入食材、數量和到期日（會依食材自動帶入冷藏天數）。快到期的食材會優先排進菜單；到期當天還剩的蔬菜會加進晚餐當「加菜」，水果和吐司改成加餐。
- **忌口與飲食類型**：可選一般葷食或蛋奶素，並排除不吃的食材（牛肉、豬肉、雞肉、魚、蝦貝類、蛋、乳製品、黃豆製品、堅果芝麻、麵包麵條）。
- **自動排菜**：從 54 道家常菜（15 道早餐、39 道午晚餐）中挑選，會考慮冰箱食材夠不夠、快到期的食材、當天還缺哪些營養（特別是鐵、鈣、纖維），以及最近是否吃過。
- **份量調整**：依熱量目標自動放大或縮小每餐份量（早 24%、午 32%、晚 28%），其餘由水果、乳品、蛋白質加餐補足。
- **白飯／糙米**：主食可改成糙米飯；米和麵會顯示大約幾碗。
- **便當**：可設定晚餐多煮一份，當隔天午餐便當（湯麵、蒸蛋、貝類除外）。
- **鎖定**：每一餐都可以鎖定；點菜名換一道後也會自動鎖定。「重新排菜單」只會換沒鎖定的餐。
- **備餐提醒**：每天列出要退冰的肉類海鮮、要多煮的便當、糙米泡水，以及快到期還沒用完的食材。
- **一週菜單**：一次看一天，手機可以左右滑動，也可以用左右箭頭或日期按鈕切換；日期上的紅點代表那天有營養素不足 80%。
- **營養打卡**：每天的熱量、蛋白質、脂肪與醣類占比、膳食纖維、鈣、鐵、維生素 C，以及蔬菜、水果、乳品份數。
- **購物清單**：列出要補買的食材和哪天開始要用；保存期短的會建議晚點再買。買好勾起來，按一下就加進冰箱庫存。也可以複製清單。
- **多人用餐**：扣庫存和補買數量會乘上人數；畫面上的份量是每人份。

## 加到手機主畫面

用手機瀏覽器打開網站後，選「加到主畫面」（iPhone 在 Safari 的分享選單，Android 在 Chrome 的選單），就能像 App 一樣打開；開過一次之後，沒有網路也能看菜單。資料都存在手機的瀏覽器裡。

## 檔案結構

```
index.html            頁面
css/style.css         手帳風格樣式
js/app.js             排菜邏輯與畫面
data/ingredients.js   食材營養素、忌口類別、冷藏天數
data/recipes.js       菜色與每人份用量
manifest.webmanifest  加到主畫面用的 App 資訊
sw.js                 離線快取（Service Worker）
icons/                App 圖示
netlify.toml          Netlify 部署設定
```

要新增菜色，在 `data/recipes.js` 加一筆即可；新增食材則加在 `data/ingredients.js`，欄位說明寫在檔案開頭。

## 部署到 Netlify

1. 登入 [Netlify](https://app.netlify.com/)，選 **Add new site → Import an existing project → GitHub**。
2. 選 `fridge-menu` 這個 repo，分支選 `main`。
3. Build command 留空，Publish directory 填 `.`（`netlify.toml` 已經設定好，通常會自動帶入）。
4. 按 **Deploy**。之後每次推送到 `main`，Netlify 都會自動重新部署。

## 營養目標

依衛福部《國人膳食營養素參考攝取量》第八版（19–50 歲）和《每日飲食指南》：

| 項目 | 目標 |
| --- | --- |
| 熱量（維持） | 體重 × 25／30／35／40 kcal（依活動量） |
| 蛋白質 | 維持 1.1、減脂 1.6、增肌 1.8 g／kg |
| 脂肪／醣類 | 占熱量 20–30%／50–60%（減脂醣類 40–55%） |
| 膳食纖維 | 14 g／1000 kcal（減脂至少 25 g） |
| 鈣 | 1000 mg |
| 鐵 | 女 15 mg、男 10 mg |
| 維生素 C | 100 mg |
| 蔬菜／水果／乳品 | ≥ 3 份／≥ 2 份／1.5–2 杯 |

食材營養素是參考台灣食品營養成分資料庫的近似值，冷藏天數為一般參考值。本工具僅供日常飲食規劃參考，有特殊飲食需求請諮詢營養師。
